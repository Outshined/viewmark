glyph buttons like 'copy id' work but silently - there's no response.  having the buttons bounce a little when pressed would at least make them more satisfying.  A tooltip flyout or simlar that says 'ID copied to clipboard' that vanishes in a second or so would be nice as well.  Think about it from a UX designer's perspective, how to make the interface more pleasant overall to work with.

## Findings
Copy ticket id, copy path, and copy link write the clipboard and return. A rejected write is ignored. Glyph buttons have no pressed style. Reply, resolve, and delete already change the card, and a menu button already opens a menu. Copy is the action whose result is off the page.

## Decision
Decided on 2026-10-22 that every glyph button uses the same short press scale, including buttons whose result is already visible. The scale goes down and back, and it is the same on every glyph button.

A flyout is for each control that copies to the clipboard. It is anchored to the button that was pressed, lasts about a second, and is shown when the clipboard write resolves. The button title stays the name of the control. While the flyout is up it takes the title's place. The flyout text is ID copied to clipboard for an id, Path copied to clipboard for a path, and Link copied to clipboard for a link. The flyout does not take focus and does not move the caret. It is not a page-level toast. A rejected write does not show the flyout.

## Acceptance
Pressing any glyph button shows that same press scale. Each copy control shows its flyout at that button after the write resolves, and the flyout is gone after about a second. A rejected write shows no flyout. Focus and the caret stay where they were.
